StackCV

AI-платформа для создания резюме по HR-стандартам

🌐 stackcv.bakha.me 📁 GitHub

Задача проекта

  • Создать веб-платформу для профессиональных резюме
  • Соответствие HR-стандартам и ATS-системам
  • ИИ для улучшения текста и оценки качества
  • Редактор оформления и экспорт PDF A4
  • Production-деплой на реальный домен
